## Repository

## Decisions and constraints

- Port the emulator to Rust using egui.
- Treat inherited upstream files as read-only unless the user specifically authorizes a change.
- The parity target is behavior established by the current web implementation and supplied assets, including documented limitations; do not silently expand scope to later 4050 models or unsupported R12 SOUND/MUSIC behavior.
- Keep emulation core and machine behavior independent of egui; UI, native file dialogs, and device panels should adapt explicit machine actions and outputs.
- Native desktop is selected. The package starts as one UI-independent library; storage should match the reference's apparent in-memory behavior. UI dependency versions and file-dialog choices remain open for the UI phase.
